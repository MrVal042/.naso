# Codex Bootstrap

Engineering decisions are governed by NASO.

Workflow:

1. Load `.naso/context.md`.
2. Load only the routed NASO documents.
3. Load repository instructions.
4. Inspect repository context.
5. Produce an implementation plan.
6. Execute.
7. Validate.
8. Report remaining risks.

NASO is the primary engineering reference.

Repository documentation provides project-specific implementation details.
