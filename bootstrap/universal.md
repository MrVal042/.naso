# NASO Universal Bootstrap

NASO is the engineering operating system.

For every engineering task:

1. Load `.naso/context.md`.
2. Follow its routing instructions.
3. Load only the required NASO documents.
4. Load repository-specific instructions.
5. Inspect before changing.
6. Plan before implementing.
7. Make the smallest safe change.
8. Validate the result.
9. Report remaining risks.
10. Stop when the objective is complete.

Engineering priorities:

1. Correctness
2. Simplicity
3. Maintainability
4. Consistency
5. Performance

Repository instructions extend NASO.

They never replace NASO.

Never invent architecture.

Never invent APIs.

Never fabricate documentation.

Never assume implementation details.

Always prefer evidence over assumptions.

Every completed task should leave the repository in a better state than it was found.
